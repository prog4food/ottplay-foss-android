# Измеренный объём JavaScript

[English](roadmap-size.md) · [Возможности](roadmap-delivery.ru.md) · [Исходные измерения](evidence/roadmap-size-20261015.json)

![Сравнение всего JavaScript одинаковыми инструментами](diagrams/roadmap-size.svg)

Здесь сохранены измерения JavaScript для указанных ниже снимков исходного кода.
Это не измерения текущей версии, установочных пакетов или сетевого трафика.

В начальном сравнении главный файл со всеми дополнительными модулями
провайдеров вырос на
**31 128 байт / 9 759 байт gzip**, то есть примерно **3,23% / 3,20%**. Это цена
новых функций; сокращение объёма или ускорение исполнения здесь не заявляется.
Xtream загружается лениво, но учитывается в полном объёме JavaScript.

Сравнены чистые архивы `bbf9ca7b` и `cae971da`, версия 1.1.55, одинаковые
Node 26.8.2, TypeScript 5.9.3, Terser 5.51.2 и zlib 1.2.12. Используются
производственные ES5-сборщик, оптимизатор, политика имён и правильный ID исходников.
Каждый файл отдельно сжимается gzip уровня 9.

- Web, главный файл: 848 092 / 262 392 → 874 926 / 270 321 байт raw/gzip.
- Web, главный файл и все провайдеры: 964 459 / 305 344 → 995 587 / 315 103.
- Native, главный файл: 848 050 / 262 460 → 874 884 / 270 372.
- Native, главный файл и все провайдеры: 964 417 / 305 412 → 995 545 / 315 154.
- Модуль M3U вырос на 184 / 82 байта; новый Xtream занимает 4 110 / 1 748.
  Остальные шесть дополнительных модулей побайтово не изменились.

До переноса ролика на here.now замена его URL на локальный путь от корня сайта
добавила один raw-байт JavaScript в этой исторической последовательности.
Это не измерение более позднего URL хостинга. Ограничение
повтора разбора HLS добавляет 37 raw / 36 gzip байт при сравнении одного снимка
([измерение](evidence/parse-recovery-size-20261015.json)). Исправление владения переходом native Auto
добавляет ещё 101 raw / 39 gzip байт
([измерение](evidence/auto-recovery-size-20261015.json)). Полный объём raw после
этих исправлений, до правок доступности, — 995 726 байт; ID сборки и gzip могут измениться в конечном коммите. Точный результат доставляемой версии —
`build/reports/classic-bundle.json` и `npm run check:size`.
Чистая сборка `652726f8` с исправлениями фокуса диалогов и мыши занимает
**995 858 raw / 315 207 gzip байт** для полного web-плеера
([данные итоговых файлов](evidence/roadmap-final-size-20261015.json)). Главный
файл — 875 197 / 270 425, полный native — 995 816 / 315 259.
Пределы этого снимка сохраняли прежний запас для native/Node/суффикса версии:
875 300 / 271 600 байт для главного файла; 996 100 / 316 400 для всех провайдеров.

## Интеграция после беты

![Полный JavaScript после интеграции beta.4](diagrams/post-beta-size.svg)

Новое сравнение воспроизводит исходный код beta.4 `39287792` и runtime
`9663b681`, включая интеграцию Plex и восстановление повреждённых настроек,
одинаковыми Node 26.8.2, Rollup 4.64.5 и Terser 5.51.2:

- Web, главный файл: 848 315 / 262 443 → 879 533 / 271 761 байт raw/gzip.
- Web, главный файл и все провайдеры: 964 876 / 305 452 → 1 000 388 / 316 600.
- Native, главный файл и все провайдеры: 964 834 / 305 520 → 1 000 346 / 316 654.
- Рост полного web-пакета: **35 512 / 11 148 байт (3,68% / 3,65%)**.

В базе учтены семь семейств провайдеров, в интеграции — восемь, включая ленивый
Xtream. Пределы главного файла в этом снимке — 879 900 / 273 000, полного набора —
1 000 800 / 317 800 байт; сохранён запас для native, Node и идентификатора релиза.
Обе локальные production-сборки пересоздают пять отслеживаемых файлов runtime
и не заявляют встроенный идентификатор чистого исходного коммита. Это локально
воспроизведённые файлы, не опубликованные бинарные файлы беты. Версии инструментов,
хеши и ограничение записаны в [данных базы](evidence/post-beta-baseline-size-20261015.json)
и [данных интеграции](evidence/post-beta-candidate-size-20261015.json).
[Отчёт о реализации](implementation-report.ru.md#интеграция-после-беты-и-повторное-ревью)
объясняет исправления и проверки.

**Границы измерения:** в суммы JavaScript не входят внешние медиадвижки,
языковые словари, CSS, изображения и видео. Исторические пакеты плеера также
содержали **A/V-ролик размером 464 652 байта**, не учтённый в суммах выше.
Его нынешняя доставка отделена от этих измерений:

- **Репозиторий:** `diagnostics/av-v1.mp4` остаётся вместе с генератором и
  проверкой для воспроизводимости. Наличие исходного файла не включает его в пакет.
- **Пакеты:** Web/OTTPlay Server, Tauri, Capacitor и Docker не содержат ролик.
  Исключено 464 652 байта исходного медиаресурса; это не измеренное уменьшение
  сжатого установщика на 464 652 байта. Его размер зависит от формата архива
  и других изменений сборки.
- **Сеть:** плеер запрашивает ролик с here.now только при явном запуске
  [A/V-проверки](audio-video-check.ru.md). Нужен интернет; для стартового
  воспроизведения ролик не загружается.

Исторические измерения JavaScript выше не изменены. Влияние URL хостинга на
JavaScript или размер нынешнего установщика требуют отдельного сравнения.
88 README — документация репозитория, не исполняемые ресурсы плеера.
Из этих чисел нельзя вывести скорость запуска, FPS, расход памяти или
производительность больших каталогов: это отдельные измерения на устройствах.
