# Фильмы и сериалы Xtream

[English](xtream-media.md) · [Улучшения](roadmap-delivery.ru.md)

Настройте Xtream, загрузите каталог каналов и откройте медиатеку. **Фильмы** и
**Сериалы** — отдельные ленивые разделы: вход в медиатеку не загружает оба
каталога. Эпизоды запрашиваются при открытии сериала. Общий Xtream-парсер создаёт
идентификаторы и URL; адаптер классического интерфейса отвечает за отображение
и время жизни запросов.

При выборе элемента его стабильная ссылка разрешается заново для текущей
учётной записи. Сохранённая запись не содержит URL потока с учётными данными.
Удалённый элемент не восстанавливается из старой строки адаптера. Смена
реквизитов, провайдера или владельца операции отменяет запросы; старый ответ
не должен заполнять экран другой учётной записи. Названия и обложки поступают
от провайдера.

Порядок: выбор раздела → авторизация и выбранный каталог → выбор фильма или
эпизода → повторное разрешение текущей ссылки → URL в памяти текущего сеанса.
[Диаграмма последовательности](xtream-media.md).

Провайдер должен разрешать запросы клиента через CORS или native-транспорт,
а устройство — поддерживать формат потока. Это не офлайн-каталог, перенос между
аккаунтами, обход DRM или транскодер. Проверка актуальности требует запроса при
выборе. Ошибка показывается существующим переведённым сообщением; недоступный
элемент не запускается.

`node tests/test_xtream_media.cjs` проверяет ленивые разделы, кодирование
реквизитов, отсутствие секретного URL в сохранённой ссылке, удалённые элементы
и отмену при смене источника. `node tests/test_provider_drivers.cjs` проверяет
жизненный цикл реального драйвера.
